## 3. EMI 文件格式

### 3.1 头部 (32 字节)

```
偏移   大小   字段         说明
0x00   2      seg_count    段数量
0x02   2      version      版本号
0x04   4      (保留)
0x08   8      magic        "MATH_TBL" 标识
0x10   4      data_size     数据总大小
0x14   4      load_addr     加载地址 (RAM)
0x18   4      id            文件 ID
```

### 3.2 段表

从偏移 `0x10` 开始，每段 16 字节：

```
偏移   大小   字段    说明
0x00   4      size    段数据大小 (字节)
0x04   4      sig     段标识 (含 VRAM 加载地址)
```

段数据从偏移 `0x800` 开始，每段按 2048 字节对齐。

### 3.3 段标识 (sig) 含义

sig 的高 16 位为 VRAM/RAM 目标地址的高 16 位：

| sig 值 | 含义 | 目标区域 |
|--------|------|----------|
| 0x1C000200 | 字库数据 | VRAM 0x1C000200 |
| 0x1E000200 | 图形/CLUT | VRAM 0x1E000200 |
| 0x1A000200 | 图形数据 | VRAM 0x1A000200 |
| 0x80016000 | 文本段 | RAM 0x80016000 |
| 0x8001A800 | 文本段 | RAM 0x8001A800 |
| 0x00000002 | 其他数据 | - |
| 0x00000003 | 其他数据 | - |

## 4. 文本段格式

### 4.1 结构

```
[指针表] [文本数据]
```

- **指针表**: 开头 u16 `ptsize` 为指针表字节数，后跟 `ptsize/2` 个 u16 指针
- **指针**: 单调递增，指向段内文本数据的偏移
- **文本数据**: 编码后的字节序列，每条以 0x00 结尾

### 4.2 文本检测条件

1. `ptsize >= 16` 且为偶数
2. 指针值单调递增
3. 最后一个指针 ≥ `段大小 - 16`
4. 文本区含 ≥ 3 个 0x12 字节

### 4.3 字符串终止符处理

0x12/0x13/0x15 后跟一个参数字节，不能误判为终止符。提取时使用 `trim()` 函数跳过转义参数。

## 6. 字库/字模格式

### 6.1 INIT.EMI 字库段

- **段号**: Seg7 (sig=0x1C000200)
- **VRAM 目标**: 0x1C000200
- **段大小**: 28672 bytes (0x7000)
- **字模大小**: 72 bytes/字模 (12×12 像素, 4bpp)
- **原始容量**: 398 字模 (28672 / 72)
- **原始字库**: 388 字模 (日文字符)

### 6.2 4bpp 像素格式

每个字模 72 字节 = 12 行 × 6 字节/行。

每行 6 字节 = 12 个 4bit 像素：
```
字节排列: [b0, b1, b2, b3, b4, b5]
像素排列: 
  像素0 = b0 >> 4 (高 nibble)
  像素1 = b0 & 0xF (低 nibble)
  像素2 = b1 >> 4
  像素3 = b1 & 0xF
  ...以此类推
```

### 6.3 灰度值

原始日文字模使用 9 级灰度 (0-8)：
- 0 = 透明/空白
- 8 = 全实/不透明
- 1,3,5,7 = 抗锯齿过渡值

### 6.4 汉化字库分配

```
全局主字库: 349 字 (索引 0-348)
  - 按字符频率排序分配
  - 最常用字符在前

全局小字库扩展: 205 字 (索引 0-204)
  - 不在主字库中的次常用字符

场景字库: 每场景最多 97 字 (索引 349-445)
  - 仅在该场景使用的字符
  - 通过同义词/近形字替换优化, 确保不超限
```

## 7. 写盘流程

### 7.1 文本段写入

1. 解析 EMI 段表，定位文本段
2. 用 `trim()` 逻辑遍历原始字符串
3. 将编码文本按顺序映射到非空原始字符串位置
4. 构建新段数据 (指针表 + 编码文本)
5. 如果新段 ≤ 原段大小 (含对齐)，直接写入
6. 如果新段 > 原段，跳过 (需手动扩展)

### 7.2 字库段写入

1. 定位 INIT.EMI Seg7 (sig=0x1C000200)
2. 写入主字库数据 (25128 bytes = 349 × 72)
3. 剩余空间填充 0

### 7.3 扇区对齐

BIN 镜像中每个扇区 2352 字节 (24 头 + 2048 数据 + 280 ECC)。
写入时必须按扇区对齐：

```python
for i in range(sectors):
    off = lba * 2352 + 24 + i * 2048  # 扇区偏移
    modified[off:off + 2048] = data[i*2048:(i+1)*2048]
```

## 8. 已知限制

1. **场景字库未写入**: 各场景 EMI 文件的场景字库段尚未写入对应字模
2. **8 个小场景文本段空间不足**: 原始段 2048 字节，新文本需 4096 字节
3. **字模格式兼容性**: 生成的字模使用 2 级灰度 (0/8)，原始使用 9 级 (0-8)，显示效果可能有差异
4. **小字库扩展未写入**: INIT.EMI 只写入了主字库 (Seg7)，小字库扩展需要写入其他段
