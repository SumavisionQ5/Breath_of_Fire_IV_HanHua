## 二、硬性规则（必须遵守）

### 1. 禁止出现任何日文字符
- **不允许**出现平假名（あいうえお…）、片假名（アイウエオ…）、长音符（ー）
- 所有日文词汇一律译为中文（意译或音译）

### 2. 控制码必须原样保留
日文原文中形如 `{xxx}` 的标记是**游戏的显示控制指令**，必须**原样搬到译文里**，位置不能改变、不能增删、不能翻译。

例：
```
原文：{框05}{立绘C240}「ああ‥、必ず。
译文：{框05}{立绘C240}「啊，一定。
```
`{框05}` 与 `{立绘C240}` 原样保留，只翻译 `「ああ‥、必ず。`

### 3. 结构标记必须保留
- `\n`（在 TSV 中以两个字符 `\` `n` 出现）= **换行**，保留在相同位置
- `---` = **分隔线**，原样保留

### 4. 人名 / 地名 / 物品名 / 技能名一律译为中文
不得保留日文原文。音译时遵循第三节的音译表。

### 5. 长度约束（重要）
- 每个汉字编码后占 **2 字节**，每个 ASCII 字符占 1 字节
- 译文**不应明显长于原文**（原文一个假名只占 1 字节，译成一个汉字要 2 字节）
- **建议译文汉字数不超过原文假名+汉字总数的 80%**
- 长句可适当拆分、精简，但不得丢失原意

### 6. 标点与符号
- 日文标点转中文标点：`、` 保留，`。` 保留，`「」` 保留，`‥`（两点省略）改成`…`
- `〜`、`～` 改为 `…` 或删除
- `！` `？` 保留

### 7. 语气与风格
- 符合中文口语习惯，**不要保留日语句式**（如"我は…です"式的倒装）
- 按角色身份翻译：粗人用粗话，贵族用敬语，小孩用短句
- 例：`おれ` → 我 / 俺；`わし` → 老夫；`ボク` → 我；`あんた` → 你

## 九、常见误区提醒

1. **不要保留日语助词**：`の` `は` `が` `を` `に` `で` `と` `て` 等一律不译，按中文语序重组
2. **不要逐字硬凑**：`休んでも、明日には‥` 不是"休ん但是明天には"，而是"歇一歇，明天也能‥"
3. **不要音译普通词**：`リスト` 是"列表"不是"利斯特"，`ボタン` 是"按钮"不是"波坦"
4. **控制码内不要翻译**：`{立绘C240}` 不能写成 `{立绘 C240}` 或 `{立绘二百四十}`
5. **保持语气标点**：`‥` 表示语气停顿，`/` 表示换行，`---` 表示分隔线，都要保留
