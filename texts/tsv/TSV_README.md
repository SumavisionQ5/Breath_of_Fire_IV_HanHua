## 二、翻译方需要知道的最重要的 5 件事

1. **不能出现任何日文假名**（あいうえお、アイウエオ、ー 都不行）
2. **`{...}` 控制码必须原样保留**（如 `{框05}` `{立绘C240}` `{队员7C}`）
3. **`\n` 表示换行、`---` 表示分隔线**，要保留在相同位置
4. **人名/地名/物品名要译成中文**，沿用 `SPEC.md` 第四节既有译名
5. **译文要短**：每个汉字占 2 字节，译名尽量精简（长音 `ー`、促音 `ッ` 不译）

## 三、推荐的处理方式

### 方式 A：逐批喂给 AI（推荐）

```
请按 SPEC.md 的规范翻译 batch_01.tsv 中的日文，
只填第 5 列 tgt，前 4 列原样保留，以 TSV 格式返回。
换行写 \n，不要改动 {控制码}。
```

一次给一个 batch（约 400-700 条），避免超出上下文。

### 方式 B：先翻译"不重复的原文"

`batch_*.tsv` 中有大量重复句子（同一句在多处出现）。若想省事，可先去重：

- 15,049 条中，**唯一原文只有 4,888 条**
- 可以只翻译唯一原文，再由我映射回所有出现位置

去重命令（可选）：
```powershell
Get-Content batch_01.tsv | Select-Object -Skip 1 |
  ForEach-Object { ($_ -split "`t")[3] } | Sort-Object -Unique
```

## 四、收回后的检查流程

翻译完成后，把填好的 `batch_*.tsv` 放回本目录（或告诉我路径），我会：

1. **逐条校验**：
   - 是否残留假名
   - 控制码是否被改动或丢失
   - `\n` / `---` 结构是否保留
   - 译文长度是否超限（会导致游戏文本溢出）
2. **自动回填**到 `translation_workbook.json`
3. **报告问题清单**（无法通过校验的条目会列出 id）
4. **生成新的游戏镜像**

## 五、注意事项

- **不要增删行**，行数必须与原文件一致（否则 id 会对不上）
- **不要改表头**
- 译文中的换行必须写成 `\n`（两个字符），**不能真的换行**，否则会破坏 TSV 结构
- 如果某条原文是空的，译文也留空
- 如果某条无法翻译，请保留 `tgt` 为空并在反馈中标注 id
